# Reference states

`TestCase/` is generated by `make` in the repo root. Only the reference
states in `bench*/` and this file are tracked. Each directory holds the three
files that LEADS writes when `DumpStateBinary = true`:

| File | Contents |
|---|---|
| `state_init.bin` | Bunch at the first time step (format in `leads_state.h`) |
| `params.bin` | Laser and run parameters (format in `leads_params.h`) |
| `state_final_arma.bin` | Final state from LEADS (Armadillo) |

## Cases

All cases use the root `input.cpp` unchanged, except for the two lines shown:
5000 electrons, gamma = 500, bunch length 4 and radius 1 at z0 = 20,
a0 = 10, a 4-cycle pulse, `dTau` = 5e-3, 8001 steps.

| Directory | `PulseModel` | `Polarization` (zeta in Model 2) |
|---|---|---|
| `bench/` | 0 | 0 |
| `bench_model2_pola0/` | 2 | 0 |
| `bench_model2_pola1/` | 2 | 1 |
| `bench_model2_pola-1/` | 2 | -1 |

The first three were regenerated on 2026-11-16 with fixes 1-4 in
`../BUGFIXES.md`. `bench_model2_pola-1/` was added on 2026-11-24. On
2026-11-24 all four were rebuilt from scratch from commit `f1f1b2c` and
came out bit-identical to the files stored here.

## Regenerating

Change the two lines in `TestCase/input.cpp`, then `make && ./leads 1` in
`TestCase/`. That overwrites `bench/`, so copy the result to the right
directory afterwards and check `git status`. A Model 2 case takes about
25 s and the Model 0 case about 18 s.
